계정 및 데이터 삭제

Pacefy · TripleA Lab Co., Ltd. (주식회사 트리플에이랩)

Pacefy 계정과 계정에 연결된 데이터를 삭제하는 방법을 안내합니다. 삭제는 되돌릴 수 없습니다.

앱에서 직접 삭제하기

  1. Pacefy 앱을 열고 로그인합니다.
  2. 하단 설정 탭으로 이동합니다.
  3. 회원 탈퇴를 선택합니다.
  4. 안내되는 확인 절차를 완료하면 계정과 데이터가 삭제됩니다.

앱을 사용할 수 없는 경우

기기를 분실했거나 앱에 로그인할 수 없다면 아래 주소로 요청해 주세요. 가입에 사용한 이메일 주소를 함께 알려주시면 본인 확인 후 삭제해 드립니다.

a3lab01.create@gmail.com — 보통 1~2 영업일 안에 처리됩니다.

삭제되는 데이터와 보관되는 데이터

데이터처리
회원정보(이메일 주소)와 프로필(닉네임·소개·프로필 이미지)탈퇴 시 지체 없이 삭제
운동 기록(거리·시간·페이스·걸음수)과 이동 경로 사본탈퇴 시 삭제
식사 기록(시각·종류·입력한 문장·추정 탄수화물 범위)탈퇴 시 삭제
커뮤니티 게시물·댓글, 1:1 대화 및 클럽 채팅 메시지탈퇴 시 삭제
지급받은 보상 쿠폰, 푸시 알림 토큰탈퇴 시 삭제
접속 로그·기기 정보수집일로부터 3개월 후 삭제
관계 법령에 따라 보존이 필요한 정보해당 법정 기간 동안 분리 보관 후 삭제

기기에 저장된 기록(운동 상세 좌표·식사 기록 원본)은 앱을 삭제하면 기기에서 함께 사라집니다.

계정을 지우지 않고 일부만 삭제하기

계정을 유지한 채로 개별 기록만 지울 수도 있습니다. 삭제한 항목은 서버에서도 즉시 삭제됩니다.

  • 운동 기록 — 기록 상세 화면에서 개별 삭제
  • 식사 기록 — 식사 화면에서 개별 삭제
  • 커뮤니티 게시물·댓글 — 해당 글에서 삭제
